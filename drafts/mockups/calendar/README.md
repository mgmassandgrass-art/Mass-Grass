# Calendar mockups (drafts, not on the site)

pages laid into each with the photo's own light, wire and punched holes kept on top. `<scene>-<page>.webp`:
scenes wide (sideboard), close (lavender), desk (painter's desk), bed (bedroom); pages 00 cover, 05, 08, 09, 12.

Rebuild: `python3 tools/calendar_mockup.py drafts/mockups/calendar 00 05 08 09 12` (writes `out-*.png`/`.webp`
there; `src/boxes.json` holds each page's rectangle). Waiting on the owner's choice before any goes on the site.

# Reference — francobollimontilessini.com
Stack: Next.js + GSAP. Fonts Cenzo Flare 900 / PP Neue Montreal. Flow: loader -> full-screen illustration shrinks into a stamp -> draggable canvas of stamps (colour per stamp, giant place names, GPS coords, dashed trail) -> click => poster page (stamp grows to full-bleed art, text fills in on scroll) -> /discover (infinite stamp field, hover = colour) -> /about credits with birds.
Takeaways: one idea everywhere (place->stamp->poster); colour per artwork; continuous transitions (same object grows/shrinks); few UI elements, motion tells the story.
